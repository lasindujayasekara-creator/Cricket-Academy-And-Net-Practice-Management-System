# Cricket Academy and Net Practice Management System

A web-based management system developed as an HND final-year project.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Main Features

- Player Management
- Coach Management
- Training Schedule Management
- Net Practice Booking
- Attendance Management
- Membership Management
- Payment Management
- Performance Records
- Reports

## Project Purpose

This system is designed to reduce manual work and improve the management of cricket academy activities, player records, training sessions, and net practice bookings.
